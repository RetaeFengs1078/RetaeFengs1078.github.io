# Haifeng Xu's academic website

An independently written static academic homepage, hosted at https://retaefengs1078.github.io/.

## Editing

- `index.html`: biography, research interests, publications, and experience.
- `assets/style.css`: typography, colors, and responsive layout.
- `assets/site.js`: optional BibTeX clipboard interaction. The site remains readable without JavaScript.
- `files/Haifeng-Xu-CV.pdf`: the current CV.
- `files/*.bib`: downloadable publication citations.

Edit the HTML directly, replace the PDF when updating the CV, and push to `master`. GitHub Pages serves the repository root. `.nojekyll` disables Jekyll processing; there is no theme, package installation, or build dependency. All fonts use the visitor's local system fonts.

The `about/`, `publications/`, and `cv/` URLs are retained for older links. Unpublished manuscripts and their internal algorithm names are not included in the site source.

## Provenance

The current HTML, CSS, and JavaScript were written from scratch for Haifeng Xu. Earlier commits used Academic Pages; the historical MIT license is retained in `LICENSE` for that earlier material. The previous template, demonstration content, and third-party placeholder portraits are no longer used.
